02 / 05
The problem

直接让 AI 做 PPT，常常跳过了最重要的一步。

01 / 输入素材很多，但目标不清楚
02 / 过程页面生成快，返工成本高
03 / 结果看起来完成了，实际难复用
内容先被整理，页面才有稳定的依据。
03 / 05
The workflow

先把思考拆开，再把页面合起来。

01需求说明
02完整素材库
03逐页大纲
04视觉样张
05章节制作

每个关键阶段都可以停下来确认；HTML 是正式修改源，讲稿独立保存。

过程可检查，结果才可复用。
04 / 05
The review loop

最有价值的不是一次生成，而是每次都能改对。

“这一页标题改一下。”
→ 只修改当前页，重新截图确认，再继续下一页。
HTML浏览器可演示
CSS可以手动调整
Notes讲稿单独保存
可修改，不等于要重新开始。
05 / 05
The result

最终得到的，不只是一份 PPT。

你得到的是一套可以继续使用的工作方式：明确的素材、可确认的大纲、可修改的 HTML、可复用的视觉模板，以及清楚的交付边界。
